# skills/

Esta pasta é gerada durante o onboarding (caminho Claude Code / Cowork — em qualquer lugar onde o Claude consiga escrever arquivos).

O Claude escreve um arquivo de skill aqui para cada tarefa recorrente identificada (trilha solopreneur) ou por função prioritária do negócio (trilha PME). Cada skill é um atalho acionável — diga uma frase específica e o Claude executa um fluxo de trabalho estruturado e consistente, feito sob medida para como você trabalha.

**Como usar:** Diga a frase-gatilho definida em cada arquivo de skill (ex. "me ajude a delimitar esta pesquisa", "me prepare para esta ligação") e o Claude roda a skill automaticamente.

Os arquivos são criados aqui por `tracks/solopreneur.md` ou `tracks/smb.md` durante a Fase 3 do fluxo de onboarding.
