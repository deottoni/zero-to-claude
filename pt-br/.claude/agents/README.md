# agents/

Esta pasta é gerada durante o onboarding (caminho Claude Code / Cowork — em qualquer lugar onde o Claude consiga escrever arquivos).

O Claude escreve um arquivo de agente aqui para cada caso de uso identificado (trilha solopreneur) ou função prioritária do negócio (trilha PME). Cada agente é uma persona ou perspectiva que o Claude assume para um tipo específico de trabalho — ex. um cético de pesquisa, um consultor de empatia com clientes, um revisor editorial, ou (PME) um ops-manager fundamentado no seu gargalo real.

**Como usar:** Referencie um agente pelo nome na sua conversa, ou deixe o Claude invocá-lo automaticamente quando o padrão combinar com o seu trabalho.

Os arquivos são criados aqui por `tracks/solopreneur.md` ou `tracks/smb.md` durante a Fase 3 do fluxo de onboarding.
