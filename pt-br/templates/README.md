# templates/

Templates gerados após o onboarding.

Esta pasta é preenchida automaticamente durante a configuração do Zero to Claude. Depois que você terminar as rodadas de contexto, o Claude identifica seus casos de uso dominantes (trilha solopreneur) ou funções prioritárias do negócio (trilha PME) e gera um template de partida para cada um.

**Exemplos do que é gerado aqui:**
- Um template de proposta ou briefing para atendimento a clientes
- Uma estrutura de rascunho para os e-mails ou posts que você mais escreve
- Um template de planejamento de projeto ou memorando de decisão
- Um formato de resumo de pesquisa ou análise
- PME: um template ligado a uma função específica, ex. um roteiro de vaga de emprego para RH ou um briefing de campanha para marketing

**Como usar estes arquivos:**
Abra qualquer template ao começar um novo trabalho. Eles já vêm pré-estruturados em torno de como você realmente trabalha — não são modelos genéricos.

Para regenerar ou atualizar um template, diga ao Claude: "Atualize meu template de [nome do template] — foi isso que mudou."
