# agents/

This folder is generated during onboarding (Claude Code path).

Claude writes one agent file here per identified use case. Each agent is a persona or perspective Claude inhabits for a specific type of work — e.g. a research skeptic, a client-empathy advisor, an editorial reviewer.

**How to use:** Reference an agent by name in your conversation, or let Claude invoke it automatically when the pattern matches your work.

Files are created here by CLAUDE.md during Phase 3 of the onboarding flow.
