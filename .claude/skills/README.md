# skills/

This folder is generated during onboarding (Claude Code / Cowork path — anywhere Claude can write files).

Claude writes one skill file here per identified recurring task (solopreneur track) or per priority business function (SMB track). Each skill is a triggered helper — say a specific phrase and Claude runs a structured, consistent workflow tailored to how you work.

**How to use:** Say the trigger phrase defined in each skill file (e.g. "help me scope this research", "prep me for this call") and Claude runs the skill automatically.

Files are created here by `tracks/solopreneur.md` or `tracks/smb.md` during Phase 3 of the onboarding flow.
