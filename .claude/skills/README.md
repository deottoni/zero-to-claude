# skills/

This folder is generated during onboarding (Claude Code path).

Claude writes one skill file here per identified recurring task. Each skill is a triggered helper — say a specific phrase and Claude runs a structured, consistent workflow tailored to how you work.

**How to use:** Say the trigger phrase defined in each skill file (e.g. "help me scope this research", "plan my week") and Claude runs the skill automatically.

Files are created here by CLAUDE.md during Phase 3 of the onboarding flow.
