# Zero to Claude
by [Andre Ottoni](https://andreottoni.com)

This repo has two complete versions of the setup — pick one, there's no auto-detection or mixing:

| | |
|---|---|
| 🇺🇸 **English** | Clone or download this repo, then open the **[`en/`](en/)** folder in Claude — see [`en/README.md`](en/README.md) for details. |
| 🇧🇷 **Português** | Clone ou baixe este repositório, depois abra a pasta **[`pt-br/`](pt-br/)** no Claude — veja [`pt-br/README.md`](pt-br/README.md) para detalhes. |

If you're not sure which folder to open, or you're pasting things into a fresh chat instead of picking a folder yourself, just open this repo's root `CLAUDE.md` and say "let's go" — it'll ask you (in both languages) which one to run, then hand off from there. / Se não tiver certeza de qual pasta abrir, ou estiver colando o conteúdo em uma conversa nova em vez de escolher uma pasta você mesmo, basta abrir o `CLAUDE.md` na raiz deste repositório e dizer "vamos lá" — ele vai perguntar (nos dois idiomas) qual versão rodar, e a partir daí assume o resto.

Optional visual preview / Prévia visual opcional: [`index.html`](index.html) — one page, both languages, toggle in the corner. Not required to run the setup. / uma página, os dois idiomas, alternador no canto. Não é necessária para rodar a configuração.
