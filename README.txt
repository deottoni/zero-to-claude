HOW TO GET STARTED
──────────────────
1. Open Claude Cowork on your Mac
2. Click "New Project" and select THIS folder (zero-to-claude)
3. Claude will greet you and walk you through everything from there

That's it. No technical setup required.


IF YOU PREFER A VISUAL GUIDE
─────────────────────────────
Open the file called "guide.html" in any web browser (just double-click it).
It shows every step with the prompts ready to copy — useful as a reference
while you're switching between Cowork and ChatGPT.


WHAT'S IN THIS FOLDER
──────────────────────
CLAUDE.md       → Instructions that make Claude run the guided setup
guide.html      → Interactive visual checklist (open in browser)
prompts/        → The 6 ChatGPT extraction prompts (for reference)
README.txt      → This file

After you complete setup, Claude will create a "my-brain/" folder here
with all your personal context files. That's your AI brain — keep this
folder safe and use it as your Cowork project going forward.
