# agents/

This folder is generated during onboarding (Claude Code / Cowork path — anywhere Claude can write files).

Claude writes one agent file here per identified use case (solopreneur track) or priority business function (SMB track). Each agent is a persona or perspective Claude inhabits for a specific type of work — e.g. a research skeptic, a client-empathy advisor, an editorial reviewer, or (SMB) an ops-manager grounded in your actual bottleneck.

**How to use:** Reference an agent by name in your conversation, or let Claude invoke it automatically when the pattern matches your work.

Files are created here by `tracks/solopreneur.md` or `tracks/smb.md` during Phase 3 of the onboarding flow.
